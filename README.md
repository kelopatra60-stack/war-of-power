# War of Power ⚔

لعبة استراتيجية عسكرية ثنائية الأبعاد للهواتف (على طراز C&C Generals / Red Alert)، بالعربية والإنكليزية.
من إنتاج **Thank7you**.

- 5 دول، خرائط متعددة (منها أرض اللافا)، قوات خاصة خيالية، طور الصمود، تحديات يومية وأسبوعية وشهرية.
- متجر (خرائط، دول، تمويهات، قوات، صرافة) ومكافآت (عجلة الحظ، الإنزال الجوي، الدخول اليومي، المهام، الإنجازات، المستويات، القصاصات الأسطورية، كود البونص).
- لعب جماعي حتى 6 لاعبين عبر الهوسبوت بلا إنترنت أو أونلاين برمز غرفة.

## محتوى المستودع

```
war-of-power/
├── .github/workflows/build-apk.yml   ← يبني APK تلقائياً مع كل رفع
├── web/                              ← كود اللعبة (HTML/CSS/JS) — راجع web/فهرس.md
├── app/                              ← مشروع أندرويد (WebView + جسر اللعب عبر الهوسبوت)
│   ├── war-of-power.keystore         ← مفتاح التوقيع (يجعل كل نسخة جديدة تُثبَّت فوق القديمة)
│   └── src/main/…                    ← MainActivity.java · NetBridge.java · الأيقونات
├── build.gradle · settings.gradle · gradle.properties
└── README.md
```

## كيف يُبنى الـ APK؟

عند كل `git push` إلى الفرع `main` يعمل GitHub Actions تلقائياً:
1. يبني اللعبة في ملف واحد: `python3 web/tools/build.py`
2. يضعه داخل التطبيق: `app/src/main/assets/www/index.html`
3. يبني APK موقّعاً ويرفعه في **Releases** باسم `War-of-Power-v1.0.N.apk`

تجد الملف في صفحة المستودع ← **Releases** (أو تبويب **Actions** ← آخر تشغيل ← **Artifacts**).

## التعديل على اللعبة

- افتح `web/index.html` في المتصفح للتجربة مباشرة (بدون بناء).
- `web/فهرس.md` يشرح مكان كل شيء في الكود.
- بعد التعديل: `git add . && git commit -m "وصف التعديل" && git push` ← يُبنى APK جديد تلقائياً.

## ملاحظات

- **مفتاح التوقيع** `app/war-of-power.keystore` (كلمة المرور `thank7you`) موجود في المستودع حتى تُثبَّت كل نسخة جديدة فوق القديمة دون حذفها. إذا أردت النشر على Google Play أنشئ مفتاحاً خاصاً بك واحفظه في GitHub Secrets بدل وضعه في المستودع، واجعل المستودع خاصاً (Private).
- يحتاج التطبيق أندرويد 5.0 أو أحدث، ويُفضَّل تحديث «Android System WebView» من متجر Play على الأجهزة القديمة.
- اللعب عبر الهوسبوت: يستخدم المنفذ 47700 (اللعب) و47701 (اكتشاف الغرف). الأصدقاء بلا تطبيق يفتحون `http://IP-المضيف:47700` في المتصفح.
