# فهرس مشروع «War of Power»

هذا الملف دليلك لمعرفة مكان كل شيء في اللعبة، حتى يكون التعديل سهلاً وسريعاً.

## طريقة العمل

1. عدّل الملف المطلوب داخل المجلدات `js/` أو `css/`. كل ملف صغير ومخصص لموضوع واحد.
2. للتجربة افتح `index.html` في المتصفح مباشرة. يحمّل الملفات بالترتيب ويعمل من دون بناء.
3. لإخراج نسخة الملف الواحد (للـ APK أو للمشاركة) شغّل من مجلد المشروع:
   ```
   python3 tools/build.py
   ```
   يُنتج الأمر الملف `dist/war-of-power.html`، وفيه كل شيء مدمج. لا تعدّل هذا الملف مباشرة، فهو يُعاد إنشاؤه في كل بناء.

> **ترتيب التحميل مهم.** ملفات js تُحمَّل بالترتيب المكتوب في `index.html` (والجدول أدناه). الملف المتأخر يستطيع استخدام ما عرّفه الملف المتقدم، والعكس غير صحيح. عند إضافة ملف جديد أضف سطر `<script src="...">` في مكانه الصحيح في `index.html`، وسيلتقطه `build.py` تلقائياً.

## هيكل المجلدات

```
web/   (داخل مستودع War of Power)
├── index.html          ← هيكل الصفحة + تحميل ملفات css و js بالترتيب (للتجربة المباشرة)
├── فهرس.md             ← هذا الملف
├── css/
│   ├── menus.css       ← المظهر العام والألوان والقوائم وشاشة التحميل
│   └── hud.css         ← واجهة المعركة
├── js/
│   ├── core/           ← أدوات عامة
│   ├── data/           ← كل الأرقام: الوحدات، الأسلحة، المباني، الدول، التطوير
│   ├── render/         ← محرك الرسم WebGL ورسام الصور
│   ├── art/            ← رسومات الوحدات والمباني والمؤثرات (مرسومة بالكود)
│   ├── map/            ← الخرائط وإيجاد المسار
│   ├── game/           ← منطق المعركة: الوحدات، القتال، المباني، الذكاء الاصطناعي
│   ├── fx/             ← المؤثرات المرئية + إعدادات اللاعب
│   ├── audio/          ← محرك الصوت
│   ├── ui/             ← الواجهة والقوائم والإدخال وملف اللاعب
│   ├── modes/          ← الأطوار: المعركة المخصصة، التدريب، الصمود
│   ├── net/            ← اللعب الجماعي عبر الشبكة المحلية
│   └── main.js         ← نقطة البداية
├── assets/
│   ├── sounds.js       ← الأصوات المسجلة (بيانات كبيرة — لا تفتحها للتعديل)
│   └── music.js        ← الموسيقى (بيانات كبيرة — لا تفتحها للتعديل)
├── tools/
│   └── build.py        ← يبني نسخة الملف الواحد
└── dist/
    └── war-of-power.html ← نسخة الملف الواحد الجاهزة (يبنيها GitHub Actions تلقائياً)
```

## الأطوار الموجودة حالياً

- **معركة مخصصة**: تختار فيها الدولة والخريطة والخصوم والمال والوقت.
- **قتال سريع** (من الشاشة الرئيسية): يعيد آخر إعداد استخدمته.
- **طور الصمود**: موجات أعداء تزداد قوة، ومعها زعيم كل خامس موجة.
- **التحديات**: ثلاثة أقسام — تحديات يومية (2) وأسبوعية (3) وشهرية (3)، نفسها لكل اللاعبين.
- **الشبكة المحلية**: حتى 6 لاعبين عبر نقطة اتصال الهاتف.
- **التدريب**.

الدول الخمس: أمريكا، روسيا، الصين، أوروبا، العرب.
الخرائط: وادي الرمال، الغابة الخضراء، سهول الشتاء، مضيق الجبال، السهوب الكبرى، الخريطة الواسعة، القارة، الأرض الشاسعة، + خرائط المتجر (واحة النخيل، التندرا، الأخدود، خط الجبهة، أرض اللافا).

## ملاحظات

- وحدات النخبة مجانية لكل لاعب في كل معركة. يمكن استدعاء كل وحدة نخبة من تبويب «القيادة» مرة كل 90 ثانية. الذكاء الاصطناعي في الصعوبة العالية يستخدمها أيضاً.
- في اللعب الجماعي يستطيع المضيف السماح بوحدات النخبة أو منعها من إعدادات الغرفة.
- الدالة `scrubRemoved()` في `js/ui/profile.js` تنظّف البيانات القديمة المحفوظة على الجهاز (الجيش الحر، خرائط الجزر، طور العالم) حتى لا تتعطل اللعبة.
- ملفا `assets/sounds.js` و`assets/music.js` كبيران جداً (7 ميغابايت معاً). تجنّب فتحهما في المحرر.

## الموارد
المال (شاحنات الإمداد + المدن) · الحديد (مناجم فوق عروق الحديد + المقر قليلاً) لبناء المباني · القطع (مستودع الموارد + المقر قليلاً) مع المال لإنتاج كل الوحدات.
ضباب الحرب كامل: ما لا تراه وحداتك الآن يبقى أسود تماماً.

## اللعب الجماعي والأصدقاء
- **عبر هوسبوت:** الشبكة المحلية القديمة (جسر أندرويد `TWNative` أو خادم المضيف).
- **أونلاين:** غرفة برمز من 5 أحرف؛ هاتف المضيف هو الغرفة وكل لاعب يتصل به مباشرة (WebRTC). خادم الربط (`NET_SIGNAL`، PeerJS) يعرّف الهواتف ببعضها فقط.
- **الأصدقاء:** رمز صداقة من 6 أحرف؛ الرسائل والدعوات عبر ntfy.sh، ومع تطبيق ntfy تصل كإشعار حتى واللعبة مغلقة. يمكن لتطبيق أندرويد تنفيذ `TWNative.notify(title, body)` لإظهار إشعار من داخل اللعبة.

## بناء APK عبر GitHub
المستودع كله (مجلد `web/` للعبة + مشروع أندرويد في `app/`) يُبنى تلقائياً عند كل رفع:
`.github/workflows/build-apk.yml` يشغّل `web/tools/build.py`، يضع الملف الناتج في `app/src/main/assets/www/index.html`، ثم يبني APK موقّعاً وينشره في **Releases**.
- واجهة أندرويد: `app/src/main/java/com/thank7you/warofpower/MainActivity.java` (WebView بملء الشاشة، زر الرجوع).
